# 🐍 Snake Game - slither-zone

> A modern, animated, multi-mode Snake Game built using pure HTML, CSS, and JavaScript.

---

## 🚀 Live Features

✨ Smooth animations & neon UI  
🎮 5 Different Game Modes (Maps)  
⚡ Adjustable Speed Control  
💀 Game Over + Pause System  
⭐ Bonus Food System (+5 points)  
🎯 High Score Tracking  
🎨 Dynamic Snake Color Changes  
🧠 Smart Collision Detection  
📱 Fully Responsive Design  

---

## 🎮 Game Modes (Faces)

| Mode | Description |
|------|------------|
| 🟢 Classic | Simple snake gameplay |
| 🟦 Box Center | Box obstacle in center |
| ✖ Cross | Cross-shaped obstacles |
| 🧩 Maze | Complex maze challenge |
| 🎲 Random Blocks | Random obstacle generation |

---

## 🕹️ Controls

- ⬆️ Arrow Up → Move Up  
- ⬇️ Arrow Down → Move Down  
- ⬅️ Arrow Left → Move Left  
- ➡️ Arrow Right → Move Right  
- ␣ Space → Pause / Resume  

---

## ⚙️ Tech Stack

- **HTML5** → Structure  
- **CSS3** → UI + Animations  
- **JavaScript (Vanilla)** → Game Logic
